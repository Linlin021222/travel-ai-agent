工具参数修复报告

问题：同一问题换个说法（“取前五名”“Alaska Airlines”）答案不变 · 修复与验证记录 · 2026-10-05

一、现象

提问修复前返回应该返回
按航司统计取消航班的条形图 1 个分组（ExpressJet 独占） 23 家航司对比
按航司统计取消航班的条形图，取前五名 与上一问完全相同（1 个分组） 前 5 名，按取消量降序
航司层级气泡图 1 个气泡（Southwest） 23 家航司气泡
Alaska Airlines航司层级气泡图 仍是 Southwest 那一个气泡 只显示 Alaska Airlines

结论：不是“回答呆板”，而是参数抽取丢了信息——用户说的“前五名”和“Alaska Airlines”根本没有传到工具， 两次提问因此落到了完全相同的参数上，输出自然一模一样。

二、根因（三个缺陷叠加）

缺陷 1：topN 默认值把“不限制”变成了 1

// 修复前 bknd/src/ai-agent/tools/dashboard-bar.tool.ts
const topN = Math.min(100, Math.max(1, Math.trunc(params.topN ?? 0) || 0));
//                              ^^^^^^^^^^^^^ 未指定 topN 时也被抬到 1

Math.max(1, …) 让“用户没说取几名”等价于“只取第 1 名”。 条形图和气泡图各有一处，所以两张图的症状完全一致。

缺陷 2：排名解析只认阿拉伯数字

// 修复前
const match = /(?:前|top|TOP)\s*(\d{1,3})/i.exec(query);   // “前五名”没有数字 → 匹配失败

中文提问里“前五名 / 前十 / 第三名”极常见，全部被漏掉。

缺陷 3：航司、机场名字没有字典

extractFilters() 从来没有为 carriers / airports 赋值—— 库里是英文名加代码（Alaska Airlines Inc. / AS），用户说的是“Alaska Airlines”“美联航”“亚特兰大”， 中间缺一张对照表，于是这些筛选条件被静默丢弃。

附带问题：模型参数覆盖了规则抽取

原来的合并顺序是 { ...规则抽取, ...模型参数 }，模型随手填的 topN=1 会盖掉更可靠的规则结果。
